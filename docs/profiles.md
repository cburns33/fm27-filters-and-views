# Profile criteria

All thresholds are minimums joined by AND. Per-90 values are rates, percentages use percent units. Early omits minutes; Midseason requires 1000; Full Season requires 2000.

The first comparison stat is a suggested sort column; views do not enforce a sort order. Other metrics provide context rather than extra hard requirements.

Positions: GK. Source: Own provisional.

- Expected Goals Prevented per 90 minutes: at least 0.1

Review columns: Save Ratio, Expected Save Percentage, Pass Completion Ratio.

Start comparison with: Expected Goals Prevented per 90 minutes.
